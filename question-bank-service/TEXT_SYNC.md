# 文本双向同步接口

服务台选择文件夹后，将类型设为“文本”，或选择“自定义”填写“小说”“文档”等名称。保存配置并启动服务后，其他软件可通过以下接口下载、新建和更新文本文件。现有题库、知识库、值班表、软件包仍为只读发布目录，不能通过本接口修改。

本功能提供服务台协议，不会自动改造或连接 NovelEditor 等其他软件；客户端需接入本协议。没有后台自动上传，也不会自动配置或发布用户提供的示例小说目录。

## 请求约定

- 使用 HTTP(S)，每次请求携带 `Authorization: Bearer <服务台访问密钥>`，上传使用 `Content-Type: application/json`。
- 类型名称为 1～40 个字符，不含控制字符或首尾空格。内置标识 `bank`、`knowledge`、`duty`、`package`、`text` 保留原有含义。
- 支持 TXT、MD、Markdown、JSON、CSV、LOG、YAML、YML、TOML、XML，子目录最多 12 层，每个目录最多 10000 个文本文件，每个文件最多 8 MiB，请求体最多 16 MiB。
- 文件作为独立文本同步，不会被拆成知识库条目，也不要求 JSON 文件符合题库结构。
- 下载原文件保留所有字节；JSON 内容接口和上传使用 UTF-8，保留文本中的 BOM 和换行符。非 UTF-8 文件可原样下载，但内容接口返回 422，需客户端先明确转换编码。
- 仅启用的文本/自定义目录开放写入，不允许绝对路径、隐藏文件、父目录跳转、Windows 设备文件或链接逃逸。

## 发现目录和文件

`GET /api/v1/text` 返回所有已启用文本目录和文件。`GET /api/v1/text/{mountId}` 只返回指定目录。

```json
{
  "folders": [{"id":"novel","name":"小说目录","kind":"小说","writable":true}],
  "items": [{
    "mountId":"novel",
    "kind":"小说",
    "path":"卷一/第一章.txt",
    "sha":"文件内容的64位SHA-256",
    "size":187548,
    "updatedAt":1790000000000,
    "downloadUrl":"/files/novel/编码后的相对路径",
    "syncUrl":"/api/v1/text/novel/编码后的相对路径",
    "writable":true
  }],
  "warnings":[]
}
```

客户端优先直接使用返回的 `downloadUrl` 和 `syncUrl`，避免中文文件名编码错误。`GET /api/v1/catalog` 的 `texts` 字段也提供同一索引。

## 下载与更新

1. `GET {downloadUrl}` 原样下载；或 `GET {syncUrl}` 返回文件元信息和 `content` 字符串。
2. 客户端保存该次下载的 `sha`。
3. 修改后 `PUT {syncUrl}`，请求如下：

```json
{"baseSha":"上次读取的64位SHA-256","content":"修改后的正文\r\n"}
```

更新成功返回 200 和新元信息（包含新 `sha`）。新建文件时使用 `baseSha:null`，成功返回 201，可创建其子目录。空字符串是有效的空文件。

文件已存在但客户端按新文件上传，或服务端 SHA 与 `baseSha` 不同，返回 409，不覆盖内容：

```json
{"error":"文件已变化，请重新下载并合并后重试","sha":"服务端当前SHA-256","path":"文件路径"}
```

客户端应保留本地改动，重新下载，合并后携带新 SHA 再上传。没有自动改名、静默覆盖或删除接口。服务台对 API 修改串行检查并原子替换；其他程序直接改写同一磁盘文件不参与该锁，建议客户端统一使用同步接口修改。

重复提交同一更新时，客户端收到超时应先 GET 核对现有 SHA/内容，再决定是否重试，避免把“响应丢失”当作“写入失败”。

## 常见响应

| 状态码 | 含义 |
| --- | --- |
| 400 | 缺少 baseSha/content 或请求格式不合法 |
| 401 | 缺少或使用了错误的服务台密钥 |
| 403 | 路径非法，或目标是只读发布类型 |
| 404 | 文件/目录不存在，或目录未启用 |
| 409 | 文件冲突，需重新读取合并 |
| 413 | 文件或请求体超过限制 |
| 415 | 不支持的文件扩展名 |
| 422 | 文件无法按 UTF-8 解码 |
